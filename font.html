Có ba cách viết CSS phổ biến khi xây dựng trang web:

CSS nội tuyến (Inline CSS): Viết trực tiếp trong thuộc tính style của thẻ HTML. Cách này giúp áp dụng nhanh nhưng làm mã nguồn rối và khó bảo trì.

CSS nội bộ (Internal CSS): Viết trong thẻ <style> bên trong file HTML. Thích hợp cho các trang web nhỏ hoặc cần tùy chỉnh riêng lẻ.

CSS ngoài (External CSS): Viết trong file .css riêng và liên kết với HTML bằng thẻ <link>. Đây là cách tối ưu, giúp tái sử dụng và quản lý dễ dàng. Trong đó, CSS ngoài là phương pháp được khuyến khích nhất để xây dựng giao diện chuyên nghiệp.
